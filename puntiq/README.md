# BRINLORE-PUNTIQ
BRINLORE PUNTIQ is een vastgoedbeheerplatform waarmee bedrijven woningen, huurders, contracten en financiën kunnen beheren. Het systeem berekent automatisch WWS/WWSO-punten en maximale huurprijzen. We bouwen het samen met Next.js, React, TypeScript, NestJS en PostgreSQL. We werken stap voor stap aan een veilig en compleet systeem.
